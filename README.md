# 📸 Insta Image Save

🚀 Full Stack Instagram Media Saver Web Application built using React.js, Express.js, and MongoDB. This project allows users to download Instagram images, reels, stories, profile pictures, and audio seamlessly with a modern and responsive user interface.

---

## ✨ Features

* 📷 Download Instagram Images
* 🎬 Download Reels
* 📖 Download Stories
* 👤 Download Profile Pictures
* 🎵 Download Audio
* ⚡ Fast & Responsive UI
* 🔐 Secure Backend API
* ☁️ Cloud Storage Support

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/insta-image-save.git
```

### Navigate to project folder

```bash
cd insta-image-save
```

### Install dependencies

```bash
npm install
```

### Create .env file

```env
PORT=8000
MONGODB_URI=
CORS_ORIGIN=*

ACCESS_TOKEN_SECRET=
ACCESS_TOKEN_EXPIRY=1d
REFRESH_TOKEN_SECRET=
REFRESH_TOKEN_EXPIRY=10d

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

### Start the server

```bash
npm start
```
